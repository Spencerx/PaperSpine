# PaperSpine5 0.4.0-alpha.1-dev

This prerelease publishes the current V5 full suite and the updated standalone Skill.

- Full suite: 26,416,717 bytes (45380d5c26b445297d55f123e65cfce67932b1804df504f05c81fc3f81ad835d)
- Standalone Skill: 717,793 bytes (f22d8fd14e2721f7f36bd6f8030273dd330f412bd970948381b6d295c05b215b)
- Full suite is Windows x64 and includes the embedded runtime.
- Install verifies SHA-256 and archives known V3/V4 Skill discovery folders only when `-CleanLegacy` is explicit.
- Task data, settings and unknown folders are preserved.
- This is a prerelease; it does not authorize external manuscript submission.
