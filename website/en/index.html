02

The workspace

One project state.
Five working stages.

The web workspace brings the current stage, pending decisions, and delivery boundary into one view. Project files remain authoritative, so new sessions, revisions, and transfers can continue from existing evidence.

PRODUCT CONTRACT

Agents advance the process. People confirm contribution, motivation, complete figures, declarations, and external actions. The local UI exposes state without replacing project truth.

03 / Why PaperSpine5?

A paper is not a one-shot generation.

The difficult part is keeping claims, evidence, figures, author decisions, and delivery requirements aligned across many rounds of work.

01 / LOCAL AUTHORITY

Files before claims

Configuration, evidence, figure decisions, the manuscript, and delivery checklists all have explicit homes. The UI is an operating surface, not the only memory.

02 / HUMAN GATES

People before external action

Contribution, motivation, complete figures, declarations, and submission authorization cannot be inferred merely because an agent can act.

03 / RECOVERABLE STATE

Recovery before repetition

Five stages share one state contract. New sessions, revisions, and transfers do not need to guess earlier scientific decisions again.

04 / From brief to publication cycle

From configuration to publication cycle,
one gated step at a time.

Every stage states what it produces, who must confirm it, and what the next stage consumes.

  1. 01

    CONFIGURE

    Configuration

    Define the task, materials, language, citations, figure route, and delivery preferences.

  2. 02

    ANCHOR

    Semantic anchors

    Confirm contribution and motivation before they constrain downstream claims.

  3. 03

    FIGURE

    Scientific figures

    Author complete candidates, review them as complete figures, and preserve decisions.

  4. 04

    CANONICAL

    Canonical manuscript

    Consume figures in the paper, then verify final pixels and five readiness dimensions.

  5. 05

    PUBLICATION

    Publication cycle

    Prepare target, revision, and transfer materials locally. There is no auto-submit button.

10 / Frequently asked

Clarify the boundary before you begin.

01Is PaperSpine5 only a Skill?

No. It is a local-first paper-production workspace installed through Skills or plugins, with a five-stage web interface.

02Are the four packages separate products?

No. They adapt installation to different hosts while sharing the same frozen core. Choose the universal package when unsure.

03Will it submit a paper automatically?

No. External submission, declarations, fees, and licenses always require explicit human authorization. Prepared is not authorized.

04Does the community atlas represent installs?

No. It only describes aggregated public GitHub Stargazer Atlas data, separately from installs, active users, and product capability.
